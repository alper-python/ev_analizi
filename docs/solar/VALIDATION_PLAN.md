# Solar Validation Plan

## Sample set

Use three properties per region:

### A - open/reference
Detached or semi-detached home with relatively open surroundings.

### B - dense urban
Row house or narrow street where neighbouring buildings materially affect
sunlight.

### C - difficult
Irregular roof, strong obstruction, trees, terrain difference or another
challenging geometry.

Regions:

- Flanders: FL-A, FL-B, FL-C
- Wallonia: WA-A, WA-B, WA-C
- Brussels: BR-A, BR-B, BR-C
- Netherlands: NL-A, NL-B, NL-C

Total: 12 properties.

## Development order

First develop the pipeline using the A property from each region.
Use the remaining eight properties primarily for validation.

## Validation targets

For each sample verify:

- building orientation
- sun azimuth/elevation
- roof-plane orientation where available
- facade orientation
- surrounding-building shadow behaviour
- hourly sunlit surface percentage
- seasonal aggregation
- theoretical vs actual sun access

External references may include:

- SunCalc for solar-position sanity checks
- ShadeMap for visual shadow comparison
- regional official solar / 3D products where available

Performance is recorded but is not an initial pass/fail criterion.
