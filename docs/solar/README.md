# DomiFrame Solar Analysis

Solar Analysis is an independent DomiFrame analysis module focused primarily
on helping a home buyer understand how a property relates to the sun
throughout the year.

The primary product question is:

> How does this home receive sunlight throughout the year, and how do the
> surrounding buildings and other obstacles affect it?

PV / solar-energy potential is a secondary layer.

## Product principles

- No single Solar Score.
- Year-round and seasonal behaviour comes before single-day exploration.
- Roofs, main facades and gardens are first-class analysis surfaces.
- Surrounding obstacles must be included wherever the available data allows.
- Raw calculations should remain separate from user-facing interpretation.
- Location may be shared with other DomiFrame modules, but Solar computation
  remains independent.
- Opening Solar from another module may carry the address/coordinates, but
  analysis must not start automatically.
